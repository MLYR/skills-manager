# AI 解读功能文档索引

状态：规划中  
建立日期：2026-08-02

本目录是 Skills Manager“AI 解读”功能的唯一规划入口，用于约束后续开发（主会话或委派子代理均可）的设计、开发、交接和验收。

仓库级强制规则位于根目录 [`AGENTS.md`](../../AGENTS.md)。本目录文档负责补充 AI 解读功能的产品、技术和协作细则。

## 已确认的产品决策

1. 功能名称统一使用“AI 解读”，不使用“AI 同步”，避免与现有 Skill 同步功能混淆。
2. 第一版只分析 Skill 主文档，不读取 `references/`。
3. AI 解读独立保存，不覆盖 `description`，不修改 `SKILL.md`，不进入 Skill Git 备份。
4. API Key 存入应用本地 SQLite `settings` 配置（沿用现有本地配置加密），AI 请求只允许由 Rust 后端发起。
5. 支持单个解析、批量解析、暂停、继续、取消和应用重启后续跑。
6. 批量解析前必须展示 Skill 数量、文本量、预计 Token 和发送内容预览，不再估算或展示金额。
7. 请求与响应日志默认保留30天，可一键清空，永远不保存 API Key 和请求认证头。
8. AI 解读必须显示“AI 生成，仅供理解参考”。
9. Skill 内容发生变化后，已有解读保留但标记为“待更新”。
10. 第一版通过 OpenAI Compatible 接口兼容云端和本地模型。

## 使用方式

- 开发开始前，所有执行者（主会话或委派子代理）必须先读完本目录四份文档和仓库根目录 `AGENTS.md`。
- 产品方案变化时，先更新 `01-overall-plan.md`，再修改代码。
- 每完成一个验收门，立即更新 `03-progress.md`，不得凭主观估计填写进度。
- 文件边界、验证和交接以 `04-agent-rules.md` 为准；不强制使用子代理。
